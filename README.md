# Gupta Properties

*Built on Trust. Bound by Loyalty.*

Premium real estate website for Gupta Properties — Noida, Vasundhara, Indirapuram and Ghaziabad.

**Stack:** Next.js (App Router) + TypeScript, Tailwind CSS, shadcn/ui, Aceternity UI, Motion, Supabase (database, auth, storage), hosted on Vercel.
